# NTE Super Sound AFK Macro

An AutoHotkey v2 (AHK v2) script designed to automate the **Super Sound** rhythm mode in *Neverness to Everness* (NTE). This macro was built from the ground up to quickly and efficiently burn City Stamina.

## ✨ Features
* **98%+ Accuracy:** Reliably hits notes to clear the Super Sound minigame.
* **Hand-Timed Precision:** Every note delay was manually recorded and calibrated.
* **Anti-Cheat Humanization:** Built-in $\pm 3\text{ms}$ randomized latency on all clicks to simulate human reaction times and avoid heuristic detection.
* **Lightweight:** Runs on native AHK v2 with virtually zero performance impact.

## 🛠️ Prerequisites
1. Download and install [AutoHotkey v2](https://www.autohotkey.com/).
2. [Download Macro File](Mayoiuta-NTE-Beats-Macro) 

## 🚀 Installation & Usage
1. Download [Mayoiuta-NTE-Beats-Macro](Mayoiuta-NTE-Beats-Macro) from this repository.
2. Right-click on the file and run it as administrator. You should see a green 'H' icon in your system tray.
3. A UI with Notes will show up
3. Open *Neverness to Everness* and load into the Super Sound mode "Mayoiuta".
4. Press **]** to start the macro.
5. Press **[ESC]** to stop the script.
6. Press F10 to SHOW/HIDE UI
